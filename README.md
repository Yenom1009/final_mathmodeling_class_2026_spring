# 捕食者-猎物恐惧生态模型

## 项目简介

本项目构建并分析了一个**捕食者-猎物生态系统模型**，引入**恐惧效应**（fear effect）来描述捕食者对猎物行为的影响。恐惧效应通过改变猎物的繁殖率、资源分配等行为参数，间接影响种群动态。

模型包含三种核心形式：
- **M0（无恐惧）**：经典 Lotka-Volterra 型模型
- **M1（瞬时恐惧）**：恐惧效应实时作用于猎物繁殖
- **M2（记忆恐惧）**：恐惧效应通过记忆变量衰减，更符合生态实际

## Pipeline 概览

项目包含 9 步自动化分析流程（`main.py`）：

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1/9 | Baseline 模型比较 | 对比 M0、M1、M2 三种模型的时间序列 |
| 2/9 | k 分岔扫描 | 扫描恐惧强度 k 对系统动力学的影响 |
| 3/9 | k-α 二维扫描 | 恐惧强度 k 与记忆速率 α 的联合扫描 |
| 4/9 | 理论边界计算 | 基于 Routh-Hurwitz 稳定性判据计算理论分岔边界 |
| 5/9 | 恐惧函数鲁棒性 | 测试不同恐惧函数形式下的系统行为 |
| 6/9 | 代表性案例分析 | 从扫描结果中选取特征案例进行深入分析 |
| 7/9 | Tritrophic 扩展 | 三级食物链扩展（猎物-捕食者-顶级捕食者） |
| 8/9 | 经验校准 | 使用经验数据校准模型参数 |
| 9/9 | 扩展模型 | 延迟模型、Leslie-Gower 模型、离散映射模型 |

## 参数说明

主要参数定义在 `params.py`，包括：

- **`prey_birth_rate`**：猎物出生率（r）
- **`attack_rate`**：捕食者攻击率（p）
- **`handling_time`**：捕食者处理时间（h）
- **`conversion_eff`**：能量转化效率（η）
- **`pred_death`**：捕食者死亡率（d₃）
- **`fear_level`**：恐惧强度（k）
- **`memory_rate`**：记忆衰减速率（α）
